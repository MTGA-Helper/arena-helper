# Arena Helper Found Capabilities

## Collection Import
* **File:** collection_importer.py
* **Purpose:** Imports user collection data and wildcards.

## Craft Priority
* **File:** craft_priority.py
* **Purpose:** Determines wildcard valuation and optimal crafting order.

## Deck Analysis & Unlock Report
* **Files:** deck_analysis.py, deck_unlock_report.py, services/unlock_service.py
* **Purpose:** Calculates missing cards, wildcard costs, and time-to-build metrics for target deck archetypes.

## Progression & Next Action
* **Files:** services/next_action_service.py, services/upgrade_service.py, ecommend_engine.py
* **Purpose:** Drives the core player loop—recommending upgrades, next crafts, and resource allocation.
